# Mason Made - Random Joke Generator

Welcome to **Mason Made** - A fun, interactive random joke generator powered by the JokeAPI!

## Features

🎭 **Random Joke Generator**
- Get single random jokes
- Fetch multiple jokes at once
- Beautiful, responsive design
- Real-time API integration

## How to Use

1. Visit the website: [Mason Made Joke Generator](https://mbrown1396-cpu.github.io/popular-games-and-websites/)
2. Click **"Get a Joke"** to fetch a random joke
3. Click **"Get 3 Jokes"** to see multiple jokes
4. Click **"Clear"** to reset

## Files

- `index.html` - Web interface for the joke generator
- `joke-generator.js` - Node.js joke generator module
- `README.md` - This file

## API Used

- **JokeAPI** (https://jokeapi.dev/) - Free joke API with no authentication required

## Technologies

- HTML5
- CSS3 (with gradients and animations)
- Vanilla JavaScript (ES6+)
- Fetch API
